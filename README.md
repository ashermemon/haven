Hi! This is Duckshot, a silly duck-shooting game made by Asher (coder), Christopher (music editor), and Arad. This is a silly game about shooting ducks flying in a bathtub. Here are the instructions:
1: Open link.
2: Click the "Play" button on the main menu.
3: Start shooting! Hover above a duck and click on it. A funny quack sound will play when you hit it. Shoot as many ducks as possible before the timer runs out!
Points: Normal duck (1 point), Silver duck (5 points), Gold duck (10 points), Dynamite (-20 points)
